Key detection test

Scores detectKey (js/audio/analyze.js) on catalog songs whose keys are listed in truth.txt. Nothing is played: previews are downloaded and analyzed silently. Serve the repo root (python -m http.server 5173) and open /tools/keytest/.

Score per song (the MIREX key score): exact 1, a fifth away 0.5, relative major/minor 0.3, parallel major/minor 0.2, anything else 0. "Blends" counts answers the Camelot wheel treats as compatible with the true key, which is what matters for mixing.
